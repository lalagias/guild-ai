E-01 · DNS RESOLUTION ERROR HIGH /scrape 8 failures · 8 credits
Occurrences
8
Credits Lost
8
Confidence
High
Root Cause

The agent scraped its own Firecrawl browser sandbox tunnel URL. The fc-<hex>.ports.firecrawl.dev hostname is ephemeral — it only exists while the browser session is active. Once the session expired/was destroyed, the domain no longer resolved in DNS. The agent then tried every TLD variation (.com, .org, .net, .test, .local, .io) before escalating to the original .ports.firecrawl.dev URL.

Fix
Never scrape the fc-<hex> tunnel URL. This is a Firecrawl-internal preview host, not the actual target site. Track the real destination URL from the browser navigation history, not the sandbox tunnel address.
