Performs web research using OpenAI's hosted web search tool via the Responses API.

Provide a research query or topic, and the agent will:
1. Send the query to OpenAI's gpt-4o model with web search enabled
2. Search the web for relevant, up-to-date information
3. Synthesize findings into a structured summary with citations

The agent uses OpenAI's hosted infrastructure, so no external search API keys are needed.

Example inputs:
- "What are the latest developments in AI agents in 2026?"
- "Compare the top JavaScript frameworks for building AI applications"
- "Research current autonomous vehicle regulations in the EU"
- "Find recent funding news about Guild.ai"
